Mac

Built on your own Mac in one step, so macOS shows no warning.

  • macOS 12 or newer
  • Apple silicon or Intel
  • Touch ID unlock

Install from Terminal

Paste this into Terminal. It puts “Wafer Wallet” in your Applications folder; running it again updates the app.

curl -fsSL https://wallet.wafer.page/install.sh | sh
  1. Open Terminal: press ⌘ Space, type Terminal, press Return.
  2. Paste the command and press Return. It downloads about 110 MB, the open-source Electron app engine from its official GitHub releases, checked by fingerprint.
  3. Wafer Wallet opens when it's done. Next time, open it from Spotlight or Launchpad.

Prefer to read the installer first? Download it as a file, then run sh ~/Downloads/install-wafer-wallet-mac.sh. Add --uninstall to remove the app.

Windows

Installed for your Windows account only, with no administrator rights.

  • Windows 10 or 11, 64-bit
  • Intel, AMD or Arm
  • 6-digit PIN unlock

Install from PowerShell

Paste this into PowerShell. It adds Wafer Wallet to the Start menu and the desktop; running it again updates the app.

irm https://wallet.wafer.page/win.txt | iex
  1. Open PowerShell: press Start, type PowerShell, press Enter.
  2. Paste the command and press Enter. It downloads about 120 MB, the open-source Electron app engine from its official GitHub releases, checked by fingerprint.
  3. Wafer Wallet opens when it's done. To remove it: Settings → Apps → Installed apps.

Android

PIN or fingerprint unlock, QR scanning and the dApp browser.

  • Android 9 or newer
  • Have version 1.5 or older? Write down your wallet's words, uninstall it, then install 1.7 and restore the wallet from its words. 1.7 is signed with a new key, so it can't install over it.
  • Version 1.7, 0.1 MB

Download the app

The app is stored on BNB Chain in parts. This page puts it together and checks its fingerprint before saving it.

Download for Android

  1. Tap the button, then open the downloaded file.
  2. If asked, allow your browser to install apps, then tap Install.
  3. Play Protect may say it doesn't know the app, because it isn't from the Play Store. That's expected.

Or install from Termux

Paste this into Termux. It puts the app together from BNB Chain, checks its fingerprint and opens Android's installer; running it again updates the app.

curl -fsSL https://wallet.wafer.page/android.sh | sh

The first time, it installs Python in Termux (about 30 MB), and Android asks you to let Termux install apps. Read the installer first.

How the apps work

The code lives on BNB Chain

The app has no wallet code of its own. Each time it starts, it reads Wafer Wallet from BNB Chain under the name wallet.circuit, from several independent nodes.

Checked before it runs

Every file must match its fingerprint on chain, or nothing runs. A new published version is used only after you agree.

Works without this website

The app keeps a checked copy, so it starts offline. If no network node answers, add your own on the start screen or under Network nodes.

The app keeps its own encrypted wallet on your device: a 6-digit PIN or your fingerprint opens it, and your 12 or 24 words are its only backup. To move a wallet to the app, or to a new device, choose Restore and type its words.

The Mac and Windows installers fetch the app files from this website or, if it can't be reached, straight from BNB Chain, and check them against the same fingerprint either way.

Self-custody. Never share your recovery phrase. Wafer will never ask for it.wallet.wafer.page
